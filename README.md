# IceRock — Investment Portfolio Manager

Десктопное приложение для управления инвестиционным портфелем.
Qt6/C++23, интеграция с Tinkoff Invest Sandbox API.

## Как запустить

1. Установить зависимости: brew install qt grpc protobuf spdlog googletest
2. Открыть в CLion папку app/
3. Добавить API-token в аргументы проекта
4. Запустить IceRock
